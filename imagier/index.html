Si le mot existe déjà dans la banque, l'image s'affiche tout de suite. Créer une nouvelle image demande le code d'accès. Pour préciser le sens, ajoutez-le entre parenthèses : avocat (le fruit).

La banque

Les images sont dessinées par une IA (FLUX) puis gardées dans une banque partagée : chaque mot n'est dessiné qu'une fois, ensuite il est gratuit pour tout le monde.

Touchez une image pour l'agrandir, et le rond pour l'ajouter à la sélection. La sélection sert à imprimer un imagier, un memory ou un loto.
